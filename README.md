# 🚬 Cigarette Detection from Images

A computer vision project developed collaboratively by **Gürkan Gür** and **Mustafa Köse** to detect the presence of cigarettes in images.

---

## 📌 About the Project

The goal of this project is to determine whether a cigarette is present in a given image using computer vision and machine learning techniques.

The project includes the development, experimentation, and analysis stages carried out during the project process.

More than being only an academic assignment, this project is important to me because it was one of the projects I developed **together with Mustafa Köse**. Working collaboratively on the problem, experimenting with different approaches, and completing the project together made it a memorable part of my university experience.

---

## 🎯 Project Objective

The main objective is to explore how computer vision and machine learning can be used for automated cigarette detection.

The project focuses on:

* Image processing
* Computer vision
* Machine learning
* Deep learning
* Image-based prediction
* Model development and experimentation

## 🔬 Development Process

The project follows a general image-processing and machine-learning workflow:

```text
Input Image
     │
     ▼
Image Processing
     │
     ▼
Feature / Pattern Analysis
     │
     ▼
Trained Model
     │
     ▼
Prediction
     │
     ▼
Cigarette Detected / Not Detected
```

The Jupyter Notebook contains the development and experimentation process used throughout the project.
